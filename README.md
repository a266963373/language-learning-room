# 多语言学习室 · 出门版

安装入口：https://a266963373.github.io/language-learning-room/

英语、日语、韩语、西班牙语、法语、俄语、阿拉伯语、印度尼西亚语和印地语。保留四种训练、复习调度、固定题卡与已有已配音材料。

iPhone可直接用Safari打开学习，也可“分享→添加到主屏幕”。电脑在Edge或Chrome打开同一网址。默认直接在线学习，教材按语言加载，已有配音在练习时逐条在线播放；无需先下载全部音频，也不另外保存播放过的音频到完整离线包。

需要断网使用时，再到“设置与内容→离线学习（可选）”下载完整九语包，约600多MB。下载可续传，已保存资源会复用；完整包就绪后才保证全部九语配音可离线播放。未保存的音频断网时会明确提示，学习进度继续保留。

刷新后保留上次保存记录，续传时先核对已有文件，再补缺少的部分；核对计数与新下载量分开显示。“设置与内容→本机存储”可查看文件占用、检查已保存内容、整理旧版本缓存，或只清理离线音频。整理保留当前可复用音频；清音频保留程序、教材、学习进度、草稿、私人录音和登录状态。缓存占磁盘空间，各设备/浏览器分别管理，浏览器的总占用估算可能稍后更新。

手机和电脑使用同一个学习账号，自动同步进度、设置、文字草稿和录音。个人同步服务使用Supabase；这里只发布公开程序与教材，不包含个人记录、登录密码或管理密钥。不开放公众注册。

原电脑本地版在“设置与内容”导出九语旅行备份，导入出门版即可继续原进度。建议先在电脑出门版导入并同步完成，再在手机登录。此后两台设备均使用此网址，原本机4317服务不会自动接收云端进度。

有网时同步；断网先存本机。不同语言的离线改动可合并；两台设备同时离线修改同一语言时，会保留两份并要求选择，避免静默覆盖。换设备前确认显示“已同步”，定期导出九语备份。

项目改动验收后会发布到这个固定网址。新版本在下次打开/刷新时启用；学习中发现更新会显示更新按钮，保留本机存档。升级不要求重新下载全部音频。

词汇估计是自评粗估，不是正式认证。内容和音频的来源、署名、许可随课程文件与 `licenses/` 提供。学习室不自动批改发音。免费云服务可能因长期不活跃暂停，已下载的本机学习仍可继续；需要时由项目所有者在Supabase恢复。
